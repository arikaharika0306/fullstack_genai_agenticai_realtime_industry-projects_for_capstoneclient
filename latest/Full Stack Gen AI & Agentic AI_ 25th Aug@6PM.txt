will build on y_test (actual ) & y_pred (predicted data) 

actual no & predicted no -- True -ve 
actual no & prediction yes -- False +Ve 
actual yes & predicted no -- False -ve 
actual yes & predicted yes -- True +ve 

confusion matrix we see the 4 components 
	tp, tn, fp, fn 
	
model accuracy == (tp + tn)/(tp+tn+fp+fn)
error rate == (fp+fn) / (tp+tn+fp+fn) | 1- accuracy  

precision == tp / predicted yes  ( you never get -ve hear) 
recall = tp / actual yes  ( you will never get -ve hear) 
f1 score == 2* (precision * recall) / precission + recall
